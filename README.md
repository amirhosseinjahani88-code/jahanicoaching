# شنا جهانی (Swim Jahani)

دموی تعاملی فاز ۱ از پلتفرم تخصصی مربیگری و تحلیل بیومکانیک شنا.
بدون نیاز به Node یا نصب پکیج اجرا می‌شود؛ فقط HTML، CSS و JavaScript ساده.

## نسخه آنلاین

دمو روی GitHub Pages منتشر شده است:

**https://amirhosseinjahani88-code.github.io/swim-jahani-app/**

هر push روی شاخه `main` به‌صورت خودکار با ورک‌فلوی `.github/workflows/deploy.yml` دوباره منتشر می‌شود.

## اجرا روی سیستم خودتان

۱. فایل `index.html` را با مرورگر باز کنید (دوبار کلیک).
۲. یا سرور محلی را اجرا کنید تا همه چیز مثل محیط واقعی باشد:

```powershell
.\serve.ps1
```

بعد آدرس `http://localhost:8777` را در مرورگر باز کنید.

## مسیر کاربر برای دیدن کل دمو

1. **لندینگ** — در جعبه «دموی تعاملی» یک جمله فارسی بنویسید و جلسه تمرین بگیرید (بدون ثبت‌نام).
2. **ثبت‌نام مربی** — دکمه «ورود / ثبت‌نام مربیان»؛ پلن شروع را مستری پرو بگذارید.
3. **کاکپیت** — هوش عملیاتی روز، میان‌برها و جلسه منتشرشده.
4. **حضور و غیاب** — «تیک زدن همه»، اسکن OCR برگه، یادداشت مربی، «تحلیل با AI».
5. **تمرین‌نویسی** — تب AI با متن یا ویس، سپس دروازه بازبینی و انتشار. تب «طراح دستی» برای ساخت ست‌به‌ست.
6. **شاگردان** — جستجو و فیلتر گروه سنی، بعد ورود به پرونده ۳۶۰ یک شناگر.
7. **آنالیز بیومکانیک** — ورودی تست ۲۵ متری و محاسبه ریت دست، DPS، سرعت و امتیاز FINA.
8. **دستیار مالی** — اسکن رسید، تأیید و ثبت خودکار در پرونده، پیام یادآوری بدهکاران.
9. **پورتال اولیا** — از پرونده شاگرد، «باز کردن پورتال» یا کپی لینک اختصاصی.
10. **پنل مستر کنترل** — پایین لندینگ: «ورود مدیر پلتفرم (دمو)» برای داشبورد BI، دایرکتوری مربیان با Ghost Login و CMS متدولوژی.

برای دیدن قفل‌های پلن پایه، در «حساب من» پلن را به اسنشیال تغییر دهید.

## ساختار فایل‌ها

| فایل | نقش |
| :--- | :--- |
| `index.html` | پوسته برنامه و ترتیب بارگذاری اسکریپت‌ها |
| `assets/styles.css` | سیستم طراحی، چیدمان راست‌به‌چپ و اجزای رابط |
| `assets/data.js` | داده نمونه: پلن‌ها، ۲۴ شناگر، ۱۲ مربی، ماژول‌های متدولوژی، اهداف مالی |
| `assets/state.js` | وضعیت برنامه در `localStorage`، احراز هویت محلی، نقش‌ها، حضور و غیاب، مالی |
| `assets/ui.js` | اعداد فارسی، نمودار SVG، توست، مودال، چیدمان مشترک، گیت ارتقا |
| `assets/ai.js` | موتور نمایشی: تمرین‌نویسی، بیومکانیک و FINA، اسکن رسید، کارنامه اولیا |
| `assets/app.js` | روتر آدرس‌ها و رجیستری همه دکمه‌ها |
| `assets/views-public.js` | لندینگ، تعرفه‌ها، ثبت‌نام، پورتال اولیا |
| `assets/views-coach.js` | کاکپیت، حضور و غیاب، شاگردان، پرونده ۳۶۰، تمرین‌نویسی، آنالیز، مالی، آرشیو |
| `assets/views-admin.js` | داشبورد BI، دایرکتوری مربیان، CMS متدولوژی |

## آنچه در این فاز واقعی است و آنچه نمایشی

**واقعی و محاسبه‌شده:**

- متراژ و ساختار جلسه تمرین بر پایه سطح، مدت، تمرکز و نوع شنا
- ریت دست، پیشروی با هر دست (DPS)، سرعت و شاخص بازده از ورودی تست
- امتیاز FINA با فرمول استاندارد `۱۰۰۰ × (زمان پایه ÷ زمان شناگر)³`
- نرخ حضور، مانده شهریه و نرخ وصول از داده‌های ثبت‌شده

**نمایشی (Mock) تا فاز ۲:**

- خوانش OCR برگه حضور و غیاب و رسید بانکی (نتیجه شبیه‌سازی می‌شود)
- متن‌های تحلیلی AI که با قاعده‌های مربیگری ساخته می‌شوند، نه مدل زبانی
- تبدیل گفتار به متن: اگر مرورگر پشتیبانی کند واقعی است، در غیر این صورت نمونه شبیه‌سازی می‌شود
- احراز هویت و پرداخت؛ همه داده‌ها فقط روی همین مرورگر ذخیره می‌شود

## قدم بعدی (فاز ۲ طرح کسب‌وکار)

- اتصال API هوش مصنوعی برای تولید داینامیک تمرین و پردازش صوت
- پایگاه داده واقعی و درگاه پرداخت بانکی
- OCR واقعی برای برگه حضور و رسید
